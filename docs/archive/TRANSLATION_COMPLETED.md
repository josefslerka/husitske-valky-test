## 🚀 Jak otestovat

### 1. Základní test
```bash
# Otevři hru v prohlížeči
open index.html

# V konzoli zkontroluj načtení:
i18n.getAvailableLanguages()
// → ["cs", "en"]

# Přepni na angličtinu:
await i18n.setLanguage('en')
```

### 2. Vizuální test
1. Otevři **Nastavení** ⚙️
2. Vyber **English** v sekci Language
3. Klikni **Save**
4. → Celé UI se přepne na angličtinu

### 3. Test jednotek
1. Jdi do **Encyclopedia**
2. Záložka **Units**
3. → Všechny jednotky mají anglické názvy a popisy

### 4. Test scénářů
1. Klikni **New Game**
2. Vyber libovolnou bitvu
3. → Název, popis, cíle v angličtině

## 🎯 Využití v kódu

### Příklady použití:

```javascript
// UI text
i18n.t('menu.newGame')
// → "New Game"

// Jednotka
i18n.t('units.CEPNICI.name')
// → "Flailmen"

i18n.t('units.CEPNICI.description')
// → "Hussite infantry with war flails. Crushing blow against armored foes."

// Scénář
i18n.t('scenarios.sudomere_1420.name')
// → "Battle of Sudoměř"

i18n.t('scenarios.sudomere_1420.briefing.hussites')
// → "You must hold the dam between the ponds..."

// Historická bitva
i18n.t('battleLore.sudomere_1420.outcome')
// → "Decisive Hussite victory. First great success of Jan Žižka..."

// S parametry
i18n.t('messages.unitMoved', { unit: 'Flailmen' })
// → "Flailmen moved"
```
